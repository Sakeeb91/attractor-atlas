# Docs index

This folder holds the written record of the project. The top-level
[README.md](../README.md) is the front page (the five specimens, their certification tables
and the reproduce commands); this page says what each document here is for and whether it is
still current.

## Reading order

1. [`docs/METHODOLOGY.md`](METHODOLOGY.md) for how every number was produced.
2. [`docs/SYMMETRY_PROGRAM.md`](SYMMETRY_PROGRAM.md) for the research plan and what came of it.
3. [`docs/RELATED_WORK.md`](RELATED_WORK.md) for the literature checks behind each novelty
   sentence.
4. The two historical documents only if you need the project's history or the workflow
   conventions (see the status labels below).

## Status of each document

| Document | Status | What it is |
|---|---|---|
| [`docs/METHODOLOGY.md`](METHODOLOGY.md) | living | The methods record: the equivariant families, the search, the certification battery, the polyhedral obstruction (section 10), the chaos-vs-symmetry law (section 11) and the reproducibility map (section 13). |
